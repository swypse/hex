# Catapult Unit and Catapult Skill Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the catapult siege unit (30 money + 20 wood + 5 ore, 3 HP, random 5–10 damage, move 1, range 4, no attack after moving, no advance on kill) plus a Catapult skill (parent Science) that gates spawning it.

**Architecture:** Extend the unit table with a `catapult` type and a `priceWood` cost field; add a `rollAttackDamage` that rolls 5–10 for catapults inside `performAttack`; add the `catapult` skill to the skill tree; wire the wood cost and skill gate through spawn/AI/spawn-dialog; commit the catapult textures and update GAME.md.

**Tech Stack:** TypeScript, PixiJS, Zustand, Vite, Vitest.

## Global Constraints

- Catapult stats: `UNIT_TYPES.catapult = { movement: 1, attack: 5, attackDistance: 4, maxHp: 3, price: 30, priceWood: 20, priceOre: 5, shape: 'square' }`. `attack: 5` is the base for AI heuristics and the HP-scaled counter; the catapult's own attack roll is `5 + floor(rng() * 6)` (5–10) per attack, computed in `performAttack` via `rollAttackDamage`.
- `priceWood: 0` is added to every existing unit; `UnitTypeInfo` gains `priceWood: number`.
- Catapult cannot attack after moving (`canAttack`), and never moves onto a killed enemy's tile (`performAttack`).
- `SKILLS.catapult`: level 1, parent `science`, description "Allows spawning catapult units (30 money + 20 wood + 5 ore).". Cost follows the formula; right after Science it is 5.
- Spawn gating: `spawnUnit` requires `hasSkill(player, 'catapult')` for catapults; all unit cost constructions include wood via `priceWood`.
- No comments in code unless asked.
- Commit after every task.
